# IndiaFOSS 2026 artwork

Official FOSS United / IndiaFOSS artwork, incorporated at the project maintainer's
request to align the Companion with the 2026 conference site.

Retrieved 8 September 2026 from https://fossunited.org/indiafoss/2026.

- `devroom-*.svg`: the eight inline devroom patterns on the landing page.
  Original source files: https://github.com/fossunited/fossunited/tree/develop/fossunited/public/images/indiafoss
  (`if26-aosp.svg`, `if26-devops.svg`, `if26-compilers.svg`, `if26-docs.svg`,
  `if26-design.svg`, `if26-hardware.svg`, `if26-rtos.svg`, `if26-security.svg`).
  The source repository is AGPL-3.0: https://github.com/fossunited/fossunited/blob/develop/LICENSE.
  Extracted as standalone SVG images; artwork colours and paths are retained.
- `if26-hero.webp`: https://fossunited.org/files/if26-hero.webp
- `if26-hero-mobile.webp`: https://fossunited.org/files/if26-hero-mobile.webp

The hero illustrations are byte-for-byte copies of the published web assets.
Logos and artwork remain credited to their original owners; this directory does
not assert ownership of the IndiaFOSS or FOSS United marks. Companion's existing
unofficial-community-app disclosure remains in Settings.

All assets are local and included in the PWA precache. Devroom images are
decorative: adjacent text supplies the programme name. They map to explicit
2026 track IDs; archives and unknown tracks do not inherit unrelated artwork.
