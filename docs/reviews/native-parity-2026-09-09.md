# PWA to native Android parity review — 9 September 2026

This is a source and navigation-path audit against main c291c9d, with local PWA browser checks. Native rendering/device behaviour is not yet verified locally: there is no Android SDK here. The PR adds native regression and screenshot cases for CI. Features listed as present are not a declaration of conference readiness.

## Validation added in this change

- Native MapRoomTest covers current IDs taking precedence, legacy-only programmes and unknown/unloaded programmes.
- Native screenshot coverage adds a long running talk title; the existing map light/dark screenshots exercise the labels.
- Native UI test taps a speaker on a talk and checks the exact person ID handed to navigation.
- PWA Now browser regression tests and a mobile track-label screenshot accompany the change.
